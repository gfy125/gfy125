## Featured Project

### [Automated Project Allocation System](https://github.com/gfy125/Auto-Allocation-System)

A website platform that allocates student groups to academic projects using skills, ranked preferences, academic performance, and project capacity constraints.

- Built a React + TypeScript interface and Node.js/Express REST API with SQLite-backed group, project, and allocation management.
- Developed a configurable matching pipeline combining Sentence Transformers and FAISS semantic similarity with weighted academic and preference scores.
- Added role-based workflows for students and administrators, input validation, allocation analytics, and manual review of results.

`React` · `TypeScript` · `Node.js` · `Express` · `Python` · `scikit-learn` · `FAISS` · `SQLite`
